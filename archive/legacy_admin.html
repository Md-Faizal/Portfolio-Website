    ⚠️ Why are mail ports showing NOT BOUND? Stalwart's Docker container runs with network_mode: host, so it has direct access to bind any port on the VM. Go to Stalwart Admin → Settings → Server → Listeners and ensure SMTPS (465), SMTP Submission (587), and IMAP (993) listeners are all created and enabled. The container being healthy at port 8080 confirms Stalwart is running — just needs internal listener setup.
